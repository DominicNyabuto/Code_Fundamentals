# 🍕 Berry's Pizzeria: Python OOP from Scratch to Pro

Welcome to the hands-on companion project for Object-Oriented Programming (OOP) in Python, modeled after the real-world pizza shop architecture showcased in the Cloud X Berry masterclass.

---

## 📂 Project Structure

Each directory represents a milestone in your progression from beginner to senior OOP practitioner:

| # | Milestone | Topic | Focus |
|---|---|---|---|
| **01** | `01_procedural_to_oop` | **Classes & Objects** | Refactoring messy dictionary scripts into clean blueprints |
| **02** | `02_encapsulation` | **Data Hiding & Properties** | `@property`, private attributes `_`/`__`, guarding state |
| **03** | `03_composition_over_inheritance` | **Architecture** | "Is-A" vs "Has-A", avoiding subclass explosion |
| **04** | `04_polymorphism_and_duck_typing` | **Polymorphism** | Eliminating `if/elif` ladders, duck typing in checkout |
| **05** | `05_abstraction_and_interfaces` | **Abstract Base Classes** | `abc.ABC`, `@abstractmethod`, pluggable payment gateways |
| **06** | `06_dunder_methods` | **Pythonic Dunder Methods** | `__repr__`, `__len__`, `__add__`, `__iter__`, `__eq__` |
| **07** | `07_class_static_methods` | **Factories & Helpers** | `@classmethod` factories, `@staticmethod` validators |
| **08** | `08_design_patterns_and_solid` | **Patterns & SOLID** | Strategy pattern, Observer pattern, SOLID principles |
| **09** | `09_capstone_project` | **Production Capstone** | Complete interactive Berry's Pizzeria ordering CLI |

---

## ⚡ How to Learn

1. Navigate to a milestone folder:
   ```bash
   cd 01_procedural_to_oop
   ```
2. Read `EXPLANATION.md` to grasp the concept and the exact pizza-shop dilemma it solves.
3. Open `exercise.py` and implement the `# TODO` sections.
4. Test your implementation:
   ```bash
   python3 test_milestone.py
   ```
5. If you get stuck, compare your work with `solution.py`.
6. Run all tests across the entire course at any time:
   ```bash
   python3 run_all_tests.py
   ```
